# Presentations

This directory contains the source files for presentations

## 01-Introduction to IMOS
- **Description**: An introductory presentation about the Integrated Marine Observing System (IMOS).
- **File**: `01-Jaine_IMOSOverview.pdf`
- **Notes**: This presentation provides an overview of IMOS, its objectives, and its significance in marine research.

## 02-IMOS Data Realiability
- **Description**: A detailed presentation on the reliability of data collected by IMOS. Ocean Best Practices (OBP) is a key focus.
- **File**: `02-Zitoun_DataReliability.pdf`
- **Notes**: This presentation discusses how IMOS uses standardised methodfoligies and implement robust QA/QC protocols.

## 03-IMOS Data Management
- **Description**: An overview of how IMOS manages its data, including storage, access, and sharing protocols.
- **File**: `03-IMOSdata.pdf`
- **Notes**: This presentation covers the data management strategies employed by IMOS to ensure data integrity and accessibility. 

## 04-IMOS Data Portal
- **Description**: A guide to the IMOS Data Portal, detailing how users can discover, access and utilise the data available.
- **File**: `04-IMOSData_accessPortal.pdf`
- **Notes**: This presentation provides insights into the functionalities of the IMOS Data Portal

## 05-IMOS Data New Portal
- **Description**: An introduction to the new IMOS Data Portal, highlighting its features and improvements over the previous version.
- **File**: `05-IMOSData_NewPortal.pdf`
- **Notes**: This presentation showcases the enhancements made in the new portal, including user interface improvements and additional data access features.

## 06-IMOS OceanCurrent
- **Description**: A presentation focused on the IMOS OceanCurrent application, which provides access to oceanographic data and visualisations.
- **File**: `06-GabiPilo_OceanCurrent.pdf`
- **Notes**: This presentation explains how users can leverage the OceanCurrent application to explore oceanographic data, including real-time and historical datasets.

## 08-IMOS Cloud-Optimised products
- **Description**: An overview of IMOS Cloud-Optimised products, detailing how these products enhance data accessibility and usability.
- **File**: `08-CloudOptimised.pdf`
- **Notes**: This presentation discusses the benefits of cloud-optimised products, including faster data processing and improved accessibility for researchers and stakeholders.

## 09-Geographic Infoirmation Systems (GIS)
- **Description**: A presentation on the use of IMOS data with Geographic Information Systems (GIS), focusing on spatial data analysis and visualisation.
- **File**: `09-GISdemo.pdf`
- **Notes**: This presentation covers the use of IMOS data, highlighting how GIS can be utilised for spatial analysis and visualisation of marine data, using Western Australia 2025 heatwave as a case study.
